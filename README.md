# Omar Ashraf — AI Engineering Portfolio

Portfolio website for Omar Ashraf, a Senior AI/ML Engineer focused on production agentic systems, voice AI, retrieval, backend platforms, and cloud infrastructure.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The site is built with React and Vite. Project diagrams and the compressed BiteWise call demo are served from `public/`.
